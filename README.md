## Lokaler Start

Alpine.js wird aus der im Lockfile festgelegten npm-Abhängigkeit bereitgestellt. `npm run serve` erzeugt die lokale JavaScript-Datei und startet Jekyll.

```sh
npm ci --ignore-scripts
bundle install
npm run serve
```
